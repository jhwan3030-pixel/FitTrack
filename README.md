# FitTrack

나의 운동 기록과 목표를 관리하는 웹 애플리케이션입니다.

## 프로젝트 소개

FitTrack은 운동 기록을 저장하고 주간 운동 목표를 설정하여
운동 현황과 목표 달성 여부를 확인할 수 있는 웹 애플리케이션입니다.

## 주요 기능

- 운동 기록 등록
- 운동 기록 조회
- 운동 기록 수정 및 삭제
- 주간 운동 목표 설정
- 주간 및 월간 운동 통계
- 운동 기록 달력
- 주간 운동 목표 달성 알림
- 목표 달성 이력 확인

## 사용 기술

- AWS EC2
- Ubuntu
- Node.js
- Express
- EJS
- MySQL
- MySQL2
- Nginx
- PM2
- HTML / CSS / JavaScript

## 데이터베이스

- exercises: 운동 기록 관리
- goals: 운동 목표 관리
- achievements: 목표 달성 이력 관리
